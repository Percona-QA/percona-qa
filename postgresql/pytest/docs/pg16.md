# PostgreSQL 16 + pg_tde (pytest)

pg_tde is supported on **PostgreSQL 16.15+** as well as 17 and 18. The pytest
suite targets majors **16, 17, 18**. Default scripts still prefer **18** unless
you set `PG_MAJOR` / `--install-dir`.

| OS | `INSTALL_DIR` | Server packages | pg_tde package |
|----|---------------|-----------------|----------------|
| Ubuntu / Debian | `/usr/lib/postgresql/16` | `percona-postgresql-16` | `percona-pg-tde16` |
| RHEL / OL / Rocky | `/usr/pgsql-16` | `percona-postgresql16-server` (+ contrib) | `percona-pg_tde16` |

## Install packages + venv

```bash
cd postgresql/pytest

# Repo line must match what Percona published (e.g. ppg-16.15).
bash setup_test_env.sh --install-pkgs \
  --pg-major 16 \
  --pg-repo-line 16.15 \
  --repo-component testing \
  --components server,pg_tde,pg_backrest

source .env.sh
# .env.sh should point INSTALL_DIR at …/postgresql/16 or …/pgsql-16
```

Or point at an existing tree:

```bash
export PG_MAJOR=16
# Ubuntu:
export INSTALL_DIR=/usr/lib/postgresql/16
# RHEL:
# export INSTALL_DIR=/usr/pgsql-16
export PATH="$INSTALL_DIR/bin:$PATH"
bash setup_test_env.sh --install-dir="$INSTALL_DIR"
source .env.sh
```

## Run the suite

```bash
# Core (skip slow / external KMS / upgrades)
pytest tests/ -v --skip-sections=slow,vault,kmip,upgrade,minor_upgrade

# Or via PG_MAJOR so --install-dir auto-resolves
PG_MAJOR=16 pytest tests/ -v -m "not slow and not upgrade"
```

## Source build (optional)

Do **not** install over package paths. Use a user prefix:

```bash
export WORKDIR="$HOME/pgwork"
export INSTALL_DIR="$HOME/pgwork/pginst/16"
export PG_BRANCH=PSP_REL_16_STABLE   # or the branch engineering hands over
bash build_from_source.sh
```

## Major upgrade involving 16

| Pair | Example |
|------|---------|
| 16 → 17 | `--old-install-dir=…/16 --install-dir=…/17` |
| 17 → 18 | existing default of `run_major_upgrade_workflow.sh` |

```bash
pytest -m upgrade \
  --old-install-dir=/usr/lib/postgresql/16 \
  --install-dir=/usr/lib/postgresql/17 \
  tests/test_tde_pg_upgrade.py tests/test_upgrade.py -v
```

Or:

```bash
OLD_PG_MAJOR=16 NEW_PG_MAJOR=17 \
  bash run_major_upgrade_workflow.sh
```

## Behaviour notes on PG 16

| Feature | On PG 16 |
|---------|----------|
| `io_method` / `--io-method-matrix` | Ignored (GUC is PG 18+) |
| `initdb --no-data-checksums` | Not used (flag is PG 18+) |
| External tablespace rewind (`@pytest.mark.pg17`) | Skipped |
| Encryption, KMIP, Vault, pgBackRest, PITR, rewind (non-ext-TS) | Supported |

Confirm binaries:

```bash
"$INSTALL_DIR/bin/postgres" --version    # expect 16.15…
ls "$INSTALL_DIR"/share/*/extension/pg_tde.control
```
